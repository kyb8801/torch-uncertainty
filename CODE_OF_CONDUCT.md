# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers at the [Discord server](https://discord.gg/HMCawt5MJu) or by opening a GitHub issue. All complaints will be reviewed and investigated promptly and fairly.
